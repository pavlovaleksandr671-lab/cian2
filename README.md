# cian2 · Стек и UI-kit Циана

Приватный учебный репозиторий для практики «Три репозитория».

```sh
# Node.js 24; при наличии nvm: nvm use
npm ci
npm run dev
```

Каталог компонентов: `/`. Исходный справочник: `/reference/`.

Кликабельный прототип аукциона: `/auction`. Пройдите настройку и публикацию как продавец, затем переключитесь на покупателя и сделайте ставку. Роли используют один аукцион. В панели «Управление прототипом» доступны готовый пример, ошибка следующей отправки, новая ставка другого покупателя, завершение и сброс. Все данные учебные, хранятся в памяти и сбрасываются при обновлении страницы. Оплата, сообщения и юридическое оформление не выполняются.

Карта экранов и план аналитики: `/auction-flow/index.html` — 32 реальных скриншота, переходы, масштабирование, метрики и таблица 33 предлагаемых событий. [Разбор сценариев и ограничения](docs/auction-flow/analysis.md). Сбор аналитики не подключён; основной прототип не изменён.

Материалы для просмотра: [карта экранов в PDF](docs/auction-flow/auction-screen-flow.pdf), [промо-ролик из реальных экранов](docs/auction-flow/auction-promo-15s.mp4) — 15 секунд, без звука, 720 × 1280.

Задачи практики — [tasks/](tasks/README.md), участники — [team/](team/README.md): у каждого свой файл `team/<github-логин>.md`. Свою работу ведите в ветке `<github-логин>/<задача>`.

React + TypeScript + CSS Modules + Vite. Всё необходимое для демонстрации работает локально. Зависимости закреплены, шрифты и UI-материалы хранятся в репозитории.

[Устройство, команды и API компонентов](docs/README.md).

Перед коммитом: `npm run typecheck && npm run lint && npm test && npm run build`.

Исходный UI-kit извлечён из публичного сайта Циана 12.11.2026. Это учебная адаптация, не официальный полный npm-пакет. Происхождение и ограничения перечислены в документации.

[Результаты проверки и скриншоты](docs/qa/README.md).
